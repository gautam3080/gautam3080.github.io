A photorealistic character creation tool for Windows, built in Unity. Users shape a realistic human head to toe in real time, from facial structure and body shape to skin, hair, and clothing. I led development and designed its core architecture.

The hard problem

50x faster character exports

Every character starts from a base model that ships with many 4K textures, several of them layered for effects, such as multiple normal maps. On export, the tool has to bake the model and keep only the textures this character actually uses, each merged into a single map. Shaders can't hand back that final texture, so the merge runs on the CPU.

I built it both ways. The first version used the classic path: read pixels, copy the texture, multiply on one thread, apply. The second rebuilt the merge on the Unity Jobs System, running the per-pixel math across cores on pixel data in NativeArrays with no texture copies. I chose the Jobs version for the export path, and it raised export throughput 50x.

A Windows tool for composing and previewing 3D scenes, built in Unity. It works like a small game editor inside the app: a scene hierarchy, a properties panel with lighting and time of day, an asset inventory, cameras, and a timeline. I built several of its core modules.

The hard problem

Hands that grip, from any direction

Automatic finger and hand placement on imported rigged characters had been open on the project for over a year. I solved it with math rather than raycasts: the solver reads the object's shape from its surface tangents, spaces each finger joint's target along the surface according to the model's bone structure, and follows the object's rotation. Those computed positions and rotations drive IK through Unity's Animation Rigging package, in real time.

Tool

A better timeline

Rebuilt the Timeline system with a horizontal layout, finer timestep control, and a more stable sequencing model.
